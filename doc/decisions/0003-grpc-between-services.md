# 0003. Між сервісами — gRPC

- Статус: прийнято
- Дата: 2026-10-26
- Джерело: стан репозиторію
- Замінено: немає

## Контекст

Gateway не містить правил автентифікації сам. Він викликає auth.

## Рішення

Виклик між сервісами — gRPC за proto з `@kinvue/contracts`.

Зараз це один виклик: gateway (`AUTH_PACKAGE`) → auth, пакет `auth.v1`, адреса `0.0.0.0:50051`, RPC `SignInWithGoogle`.

Цільовий план малює виклики сервісів, але не наказує замінити цей gRPC на HTTP. Таку заміну робить лише тікет, який прямо про це каже. Див. [0008](0008-target-ingress-and-plan.md).

## Порушення

HTTP між gateway і auth. Новий міжсервісний виклик без proto. Клієнт, який обходить згенеровані типи `@kinvue/contracts`.

## Наслідки

Новий сервіс спочатку отримує proto, потім gRPC-слухача і клієнта в gateway. Публічним лишається HTTP gateway.

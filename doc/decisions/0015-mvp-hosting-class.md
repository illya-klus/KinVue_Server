# 0015. Клас хостингу MVP

- Статус: прийнято
- Дата: 2026-10-26
- Джерело: чат 2026-10-26, KIN-123
- Замінено: немає

## Контекст

Ціль архітектури — модель на 100 тисяч одночасних користувачів. Бюджет демо/MVP — близько $300 на місяць. Вендорів ще немає.

## Рішення

- Місячний бюджет цілі: не вище $300.
- 100 тисяч одночасних користувачів — архітектурна модель, не закупівля для v1.
- Клас обчислень: контейнери на невеликій VM або керованій контейнерній платформі, без вимоги Kubernetes.
- Дані: керовані PostgreSQL, MongoDB, Redis, AMQP, об’єктне сховище і CDN, якщо бюджет дозволяє. Конкретний вендор дописують, коли оператор його обере.
- Production Redis має бути здатний до HA. Локально дозволений один вузол.
- Kubernetes, кілька CDN і аварійне відновлення в кількох регіонах у це рішення не входять.

## Порушення

Закласти потужність на 100k CCU для MVP. Поставити Kubernetes як обов’язкову топологію v1. Обрати вендора в коді без запису тут.

## Наслідки

Тікети провіжінінгу кажуть «керований Postgres / Mongo / Redis / AMQP / object storage / CDN», а не конкретний бренд, доки оператор не допише вендора в цей файл.

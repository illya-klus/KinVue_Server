# 0011. Анонімне читання опублікованих фільмів

- Статус: прийнято
- Дата: 2026-10-26
- Джерело: чат 2026-10-26, KIN-78
- Замінено: немає

## Контекст

Модель безпеки каже, що API захищений JWT. План впровадження ставить пошук і картку фільму в публічні маршрути. G-07 лишала це відкритим.

## Рішення

- `GET` пошуку фільмів — анонімний.
- `GET` картки фільму — анонімний лише для опублікованих.
- Watchlist, доступ до медіа і адмінські маршрути вимагають автентифікації в будь-якому разі.

Речення «API захищений JWT» у [22_SECURITY_MODEL.md](../design/22_SECURITY_MODEL.md) більше не читають як «кожен HTTP-маршрут вимагає токен». JWT лишається обов’язковим для автентифікованих маршрутів.

## Порушення

Вимагати JWT на публічний пошук або на картку опублікованого фільму. Віддавати неопублікований фільм або медіа без входу.

## Наслідки

G-07 закрита цим записом. Маршрути gateway для каталогу мають бути публічними, коли їх додадуть.

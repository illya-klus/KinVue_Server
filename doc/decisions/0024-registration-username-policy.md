# 0024. Правило username для реєстрації

- Статус: прийнято
- Дата: 2026-10-28
- Джерело: чат 2026-10-28, явне погодження користувача; KIN-313
- Замінено: немає

## Рішення

Прийняти правило з плану: username — 3–30 символів ASCII `a-z`, `0-9`, `_`. Перед перевіркою прибрати крайові пробіли й привести до нижнього регістру. Users володіє унікальним індексом username. Auth передає нормалізований username та глобальний userId через gRPC, згідно з 0003. displayName — непорожній текст до 100 символів. Password — щонайменше 12 символів, без обрізання та зміни регістру, максимум 1024 UTF-8 bytes як захист ресурсів.

## Межі

Користувач погодив правило. Успіх реєстрації потребує підтвердженого профілю Users.

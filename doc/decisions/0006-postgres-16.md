# 0006. PostgreSQL 16 для даних auth

- Статус: прийнято
- Дата: 2026-10-26
- Джерело: стан репозиторію
- Замінено: немає

## Контекст

Локально і для auth потрібна одна база. Prisma Next у цьому сервісі налаштований на PostgreSQL.

## Рішення

- Рушій: PostgreSQL 16.
- Локальний контейнер описаний у кореневому `docker-compose.yml`, сервіс `postgres`, ім'я бази `kinvue`, порт `5432`.
- Міграції auth лежать у `services/auth/migrations`.

Пароль і URL підключення в документацію не копіюють. Вони лишаються в compose і в `.env`.

## Порушення

Інший рушій бази для auth. Другий compose, який підміняє цей Postgres. Міграції auth поза `services/auth/migrations`.

## Наслідки

Нові таблиці auth додають міграцією Prisma Next до цієї бази, а не окремим SQL-файлом у іншому сервісі.

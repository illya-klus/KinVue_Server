# 0010. Стек v1 цього бекенд-репозиторію

- Статус: прийнято
- Дата: 2026-10-26
- Джерело: чат 2026-10-26, KIN-26
- Замінено: немає

## Контекст

KIN-26 просить прийняти стек і структуру з плану впровадження: TypeScript, Node 20, pnpm, Turborepo, NestJS, React/Vite, дерево `apps/`. У цьому репозиторії вже є pnpm і Nest, код лежить у `services/*`, веб-клієнт живе в іншому репозиторії. План писав Node 20, CI вже ставив Node 24. Карту портів з плану не чіпаємо: для портів є окремі тікети.

## Рішення

- Цей репозиторій — лише бекенд KinVue. Фронтенд не додають сюди.
- Мова: TypeScript. Менеджер пакетів: pnpm. HTTP-сервіси: NestJS.
- Node.js: 24. Текст плану про Node 20 для цього репозиторію не діє.
- Пакети: `services/*` і `packages/*`. Дерево `apps/` з плану не заводимо.
- Цільові сервіси v1: gateway, auth, users, movie, rooms, notifications, transcode-worker. Каркас `services/chat` у продукт не розбудовують ([0008](0008-target-ingress-and-plan.md)).
- Turborepo не ставимо. Поки пакетів мало, кореня вистачає `pnpm -r` і `pnpm --filter`. Turbo можна розглянути окремим тікетом, коли CI почне ганяти зайві пакети або знадобиться віддалений кеш.
- Карта портів із плану цим записом не приймається і не замінюється.
- CI runner: зафіксована `ubuntu-24.04`, не `ubuntu-latest`. Версія Node у workflow — 24.

## Порушення

Додати вебзастосунок у цей workspace. Перейти на Node 20. Поставити Turborepo попутно з іншим завданням. Поставити CI на `ubuntu-latest`. Перейменувати `services/` на `apps/` без тікета.

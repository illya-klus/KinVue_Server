## Goal

Let users view/edit profiles, search users, manage friend requests, and see friends list.

## Scope

Profile, search, friend request, and friends pages plus social E2E test.

## Out of scope

Do not build movie search or watch rooms in this epic.

## Suggested order

1. KIN-231: Build profile view + edit form
2. KIN-232: Build user search page (min 2 chars)
3. KIN-233: Build friend requests UI (send, incoming, outgoing, accept, reject)
4. KIN-234: Build friends list page
5. KIN-235: E2E: user A finds user B, sends request, B accepts, both see friendship

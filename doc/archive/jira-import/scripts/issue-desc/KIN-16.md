## Goal

Admin and user-facing movie pages: create/edit, publish, search, detail, watchlist.

## Scope

Admin movie pages, debounced search, detail + watchlist actions, movie E2E test.

## Out of scope

Do not build watch rooms or media upload UI in this epic.

1. KIN-321: Admin movie create/edit pages
2. KIN-322: Admin publish now + schedule publish UI
3. KIN-323: Movie search page with 300ms debounce + min 2 chars
4. KIN-324: Movie detail page + watchlist add/remove
5. KIN-325: Watchlist page
6. KIN-326: E2E: admin publishes movie → user searches → saves to watchlist

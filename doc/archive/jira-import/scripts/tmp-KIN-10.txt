## Goal
Provide the single HTTP edge for KinVue: routing, JWT validation, rate limits, and admin scope guards.

## Scope
Public, authenticated, and admin route proxies; JWKS cache; request-ID forwarding; Gateway tests.

## Out of scope
Do not implement business logic in Gateway — proxy and edge concerns only.

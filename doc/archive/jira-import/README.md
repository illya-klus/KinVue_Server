# Архів імпорту в Jira

Скрипти, пакети JSON і чорнові описи `scripts/issue-desc/` лишились від заведення тікетів на дошку.

Це не план і не вимоги. Агент їх не запускає, щоб «досинхронізувати» дошку, і не переносить звідси продуктових правил у код.

Частина скриптів дивиться на інший каталог на диску і на ключ Atlassian зі змінних оточення. Секрети в цих файлах не зберігаються. Шляхи і ключ хмари теж не є контрактом сервера.

# Журнал чатів

Один файл на день: `YYYY-MM-DD.md`. Секції дописують у кінець. Минуле не редагують і не видаляють.

Сюди потрапляє кожне рішення чату, включно з відмовами і тим, що вирішили не робити. Шаблон секції: [session-log.md](../templates/session-log.md).

Якщо рішення зобов'язує майбутню роботу, журналу мало: потрібен ще файл у [decisions](../decisions/README.md).

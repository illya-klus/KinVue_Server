## Що в плані вже поправлено під цей репозиторій

- Репозиторій — сервер, який уже збирається. Знімок коду: [architecture.md](../architecture.md). Огляд беклогу більше не називає репозиторій порожнім.
- Папки лишаються `services/*` і `packages/*`. Дерево `apps/` з плану сюди не копіюють.
- `services/chat` — порожній каркас. Окремий Chat Service план відхиляє: чат живе в Rooms.
- У коді refresh живе 7 днів і ніде не зберігається. План пропонує 30 днів, ротацію і відкликання. Це не зроблено. Термін не міняють мимохідь.
- Gateway кличе auth по gRPC. Малюнки плану транспорт не перейменовують. Заміну робить тікет про транспорт.
- CI ставить Node 24. Текст плану пише Node 20. Пайплайн у цьому розкладі не чіпали: CI/CD як шлюз ще не налаштовуємо.
- Відкриті дірки зібрані в [09-gaps-and-unknowns.md](../backlog/engineering/09-gaps-and-unknowns.md). Поки їх не закрили окремим рішенням, це не вимоги.
